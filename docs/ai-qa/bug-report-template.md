# AI-Assisted Bug Report Template

## Title
Describe the defect in a crisp, user-impact-focused title.

## Summary
Explain the bug in one or two sentences.

## Environment
- Browser: Chrome / Firefox / Safari
- OS: Windows / macOS / Linux
- Build / version: 
- URL: 

## Steps to Reproduce
1. Navigate to the application
2. Sign in with valid credentials
3. Add an item to the cart
4. Proceed to checkout
5. Observe the failure

## Expected Result
Describe the intended behavior.

## Actual Result
Describe the incorrect behavior.

## Evidence
- Screenshot
- Video
- Trace file
- Console logs

## Severity
- Critical / High / Medium / Low

## Proposed Fix
Briefly suggest the likely resolution.

## AI Prompt

> Convert this failed test result into a polished bug report for a Jira ticket. Include severity, root cause hypothesis, reproduction steps, and a concise expected vs actual summary.
