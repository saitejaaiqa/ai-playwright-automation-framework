# AI-Generated Test Scenarios

## Objective
Use AI-assisted reasoning to expand test coverage beyond happy-path automation. This file demonstrates how a QA engineer can prompt an AI assistant to identify high-risk user journeys and prioritize regression testing.

## Sample Prompt

> Review the SauceDemo application and propose the highest-value regression scenarios for login, product selection, checkout, and user session flows. Prioritize test cases by risk, business impact, and automation cost.

## Suggested Scenarios

1. Login with valid user credentials
2. Login with locked-out account
3. Login with empty username/password
4. Add item to cart from inventory page
5. Remove item from cart
6. Validate product name and price consistency
7. Logout and session invalidation
8. Access inventory without login should redirect to login page
9. Check out with valid data
10. Check out with missing information

## Why This Matters
AI-assisted scenario generation helps teams reduce blind spots, uncover edge cases, and continuously improve automation strategy.
