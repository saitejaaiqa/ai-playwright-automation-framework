# AI-Powered Playwright Automation Framework

A professional, enterprise-ready Playwright + TypeScript automation framework designed for UI regression testing, API validation, and AI-assisted QA reporting. This project is built as a portfolio and freelance showcase to demonstrate advanced automation engineering capabilities for international clients.

## Overview

This framework is structured around the Page Object Model (POM), test data management, reusable utilities, CI/CD execution, and AI-assisted debugging workflows. It targets the public SauceDemo application for realistic automation scenarios while showcasing scalable architecture for production-grade test suites.

## Architecture

The project follows a layered architecture:

- tests: business-flow automation scenarios
- pages: encapsulated UI interactions and locators
- fixtures: reusable test setup and dependency injection
- api: request-based validation layer
- utils: environment handling and helper functions
- test-data: user credentials and expected data
- reports: generated test artifacts and HTML outputs

## Core Features

- Page Object Model architecture
- TypeScript-based typed test suite
- Cross-browser execution: Chromium, Firefox, WebKit
- Retry and failure capturing for stability
- HTML reporting and JUnit reporting
- Screenshot and video capture on failure
- API validation with Playwright request context
- Data-driven user and product management
- GitHub Actions CI pipeline
- AI-assisted debugging and bug reporting documentation

## Installation

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Install Playwright browsers:

```bash
npx playwright install --with-deps chromium firefox webkit
```

## Execution Commands

Run all tests:

```bash
npx playwright test
```

Run Chromium only:

```bash
npx playwright test --project=chromium
```

Run tests in headed mode:

```bash
npx playwright test --headed
```

Open HTML report:

```bash
npx playwright show-report reports/html-report
```
